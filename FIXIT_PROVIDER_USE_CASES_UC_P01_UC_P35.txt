→ SELECT PROVIDER TYPE
→ COMPLETE PROFILE
→ VERIFICATION

→ SET AVAILABLE
→ RECEIVE SERVICE REQUEST
→ REVIEW
→ ACCEPT / DECLINE / REQUEST CLARIFICATION
→ IF ACCEPT: WAIT FOR CUSTOMER SELECTION
→ IF SELECTED: ACCEPTED
→ SCHEDULE INSPECTION
→ ARRIVE
→ INSPECT
→ OPTIONAL COST INFORMATION
→ START WORK
→ IN_PROGRESS
→ SCOPE CHANGE IF REQUIRED
→ COMPLETE WORK
→ CUSTOMER CONFIRMS / DISPUTES
→ COMPLETED
→ REVIEW / HISTORY / WARRANTY / SUPPORT
